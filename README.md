## Project Overview

This project explores the connection between creative coding and music through a cheerful composition developed using Python in TunePad. The project combines melodies inspired by Vietnamese folk music with modern musical elements to create a lively and positive atmosphere.

Growing up in Vietnam, traditional music and instruments such as the bamboo flute and đàn tranh have always been connected to my childhood memories. Instead of creating a completely traditional piece, I wanted to bring these cultural influences into a modern composition by experimenting with piano melodies, chords, bass, and electronic drums.

The aim of this project is to explore how coding can be used as a creative tool to express emotions through music. By experimenting with different notes, rhythms, and musical patterns, I wanted to understand how Python can transform simple lines of code into an engaging musical composition while reflecting my personal connection to Vietnamese lyric.



## Technologies Used

- **TunePad:** An online creative coding platform used to write, test, and arrange different musical sections, including Intro, Melody, Chord, Bass, and Drums.

- **Python:** The programming language used to create musical notes, melodies, and rhythmic patterns. The project uses functions such as `playNote()`, as well as variables, lists, and loops to control pitch, note duration, and chord patterns.

- **Musical Instruments:** Piano is used for the Intro, Melody, and Chord sections, while Bass provides lower notes to support the composition. Electronic drums add rhythm and energy, combining Vietnamese folk-inspired melodies with modern musical elements.

- **Sound Library:** TunePad's 808 Drumkit is used to create electronic percussion patterns, helping make the composition more lively and energetic.


## Musical Composition Structure

**Project settings:**
- Tempo: 120 BPM
- Time signature: 4/4
- Key: C major
- Pentatonic notes: C, D, E, G, A

### Intro

The Intro is an 8-beat opening section using piano notes to introduce the cheerful mood of the composition. It establishes a simple musical atmosphere before the main melody begins.

### Melody

The Main Melody is inspired by Vietnamese folk music and my exploration of Phạm Duy's album Folk Songs of Viet Nam (1968). The Melody is a 12-beat section inspired by Vietnamese folk music. It uses notes from the C major pentatonic scale (C, D, E, G, and A) to explore a cheerful and energetic musical style while reflecting my cultural inspiration.

### Chord

The Chord section is 12 beats long and uses two Python functions, `majorChord()` and `minorChord()`, to create groups of notes. A `for` loop plays the notes sequentially, creating an arpeggio-like pattern that adds harmony and musical variation.

### Bass

The Bass section uses a repeating 4-beat pattern with lower notes, including C3 and G3. It provides a deeper musical foundation and supports the piano melody and chord patterns.

### New Drums

The New Drums section uses TunePad's 808 Drumkit to create a 4-beat percussion pattern. It adds rhythmic energy to the composition and helps combine the Vietnamese folk-inspired melody with a more modern musical atmosphere.

## How It Works

The project uses Python in TunePad to turn programmed notes and rhythmic patterns into music.

The playNote() function plays individual notes using numerical pitch values. Higher pitch values produce higher notes, while lower values produce lower notes. The beats parameter controls how long each note is played.

The project also includes two functions, majorChord() and minorChord(), which organise notes into major and minor chord patterns. A for loop is used to play these notes sequentially, creating an arpeggio-like effect.

The music is divided into five TunePad cells: Intro, Melody, Chord, Bass, and New Drums. Each cell contains a different musical element that contributes to the composition.

## Project Development

I started this project to create happy music inspired by Vietnamese traditional melodies. One of my biggest challenges was finding the right musical style, as my first melodies were not energetic enough. I experimented with different notes, bass, and drum patterns to improve the sound. Through this process, I learned how Python can be used to create music and how small changes in rhythm and melody can affect the overall mood.

## Limitations and Future Improvements

One limitation is that the Vietnamese folk influence is not as clear as I originally wanted because the composition mainly uses piano and electronic sounds. The melody could also be more catchy and energetic. In the future, I would like to explore more  more memorable and energetic, try different instruments, and improve the combination of melody, bass, and drums.
